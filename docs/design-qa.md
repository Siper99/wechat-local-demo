# WeChat 1.3.0 跟进 2026 年新版微信界面

依据 2026 年 iOS 微信 8.0.75–8.0.78 的公开更新报道整理。多数改动在官方为灰度测试，不同账号可能看到不同样式；本版选取与本应用已有页面相关的部分。

| 新版微信改动（报道） | 1.3.0 实现 |
|---|---|
| 会话左滑“标为未读/删除”由直角矩形改为圆角按钮（8.0.78 灰度） | 自定义左滑：圆角蓝色“标为未读”、红色“删除”，删除再点一次变“确认删除”；置顶等移到长按菜单；横向拖动不会误开聊天 |
| “按住说话”去掉描边，更圆润扁平、字体更粗；右侧新增独立“语音转文字”图标（8.0.78 灰度） | 语音模式按钮 10 pt 圆角、无描边、半粗体，右侧语音转文字图标（功能未接入，点击有说明） |
| 发送图片/视频改为白底半屏显示（2026 年 9 月灰度） | ＋ → 相册改为白底半屏选图，可上拉全屏，最多 9 张，按选择顺序发送 |
| 好友资料页右上角新增“编辑”按钮，直达备注（2026 年 9 月灰度） | 资料页按微信样式重做：白色资料区、备注和标签、朋友权限、朋友圈、更多信息、发消息/音视频通话；右上角编辑和更多（删除联系人） |

[1.3.0 构建与测试](https://github.com/Siper99/wechat-local-demo/actions/runs/35712754537)：IPA 构建成功，iPhone 16 / iOS 18.5 模拟器 5 项 UI 测试全部通过（新增 `testSwipeActionsPhotoSheetVoiceAndProfile`：左滑→删除→确认删除、半屏选图、语音输入样式、资料页发消息）。截图：[左滑菜单](screenshots/14-swipe-actions.png)、[半屏选图](screenshots/15-photo-sheet.png)、[语音输入](screenshots/16-voice-input.png)、[好友资料](screenshots/17-contact-profile.png)。

实现说明：iOS 18 上 SwiftUI 的 DragGesture 会被 ScrollView 抢走，左滑改用 UIKit 平移手势（仅横向时开始，滚动视图等待其失败）；iOS 17 仍用 DragGesture。拖动过程中及刚结束的点按被忽略，避免左滑时误进聊天。

未跟进：文件图标新样式（本应用没有文件消息）、小微 AI 助手与“按住问小微”、公众号耳机入口、液态玻璃风格应用图标（图标来源另有许可限制）。

# WeChat 1.1.0 界面与交互验证

本轮范围由用户确认为“先把主要页面和聊天交互做像”。实现保持 SwiftUI / SwiftData 原生应用，使用现有本地人物和对话数据。

## 参考依据

- [SwiftUI-WeChat](https://github.com/wxxsw/SwiftUI-WeChat)：主要页面截图、底部导航、输入区布局及图标资源。
- [WeChatSwift](https://github.com/alexiscn/WeChatSwift)：会话行 72 pt 高、头像 48 pt、左侧 16 pt 间距及发现页分组。
- 微信 App Store 展示图：辅助核对灰色背景、搜索栏和白色/绿色聊天气泡。
- 图标许可与资源归属保留于 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) 和应用内“我 → 设置 → 开源许可”。

## 检查方法

通过 GitHub Actions 的 macOS / Xcode 16.4 构建 Release 真机 IPA；在 iPhone 16、iOS 18.5 模拟器上运行中文、浅色模式 UI 测试并导出截图。UI 测试使用独立内存数据库，不修改正式数据。

参考仓库截图宽 414 pt，当前模拟器约 393 pt；按原生布局尺寸、层级和相对间距核对，未进行同尺寸逐像素比对。示例人物、头像和消息内容也不同。结果不代表与任意版本官方微信完全一致。

## 已知差异与未验证范围

- 这是主要页面及本地聊天交互的仿真版本；朋友圈、视频号、支付、群聊、语音与视频通话未实现。
- 消息长按菜单、相册/相机选择器和粘贴授权采用 iOS 系统控件，与官方微信的部分自定义样式不同。
- 联系人未设置图片时使用文字头像；未复制参考截图中的个人资料和聊天数据。
- 转发、多选删除和撤回已实现，但本轮 UI 自动化未逐一覆盖；相机、相册权限及深色模式尚未真机验证。
- 未在用户的实体 iPhone 上安装本轮构建。1.0.1 到 1.1.0 的 SwiftData 字段均有默认值，Bundle ID 保持不变；尚未进行实体设备旧数据库迁移验证。
